# Trust Me, I'm AI: Supplemental Material
Supplementary material for the paper "Trust Me, I'm AI: A User-Centric Review of Human-Machine Interaction and Teaming with Explainable AI" by Doreen Jirak, Pieter Maes, and Dirk van Rooy.

Source: (https://ieeexplore.ieee.org/document/11479585)

- Figures: all figures (except for gradCAM and attention-based models, please see the source references in the paper) are located in "/pics" folder including a python notebook reproducing a PDP plot provided by "scitkit learn" (adapted to a shorter version with other figure parameters).
- References: all references including the reviewed studies can be found in the "bib" file.
- An additional overview of cognitive biases is included in the corresponding pdf.
